# Texture credits

Planetary textures live in this directory and are loaded lazily, only once a body is
close enough to the camera to be drawn as a mesh.

Every file added here must be recorded below with its source and license.

| File | Body | Source | License |
|---|---|---|---|
| _(none yet)_ | | | |

## Intended sources

- **[Solar System Scope](https://www.solarsystemscope.com/textures/)** &mdash; maps for
  every planet plus the Milky Way. CC BY 4.0: attribution required.
- **[NASA Scientific Visualization Studio](https://svs.gsfc.nasa.gov/)** and
  **[JPL Photojournal](https://photojournal.jpl.nasa.gov/)** &mdash; generally public
  domain, but verify case by case.
- **[USGS Astrogeology](https://astrogeology.usgs.gov/search)** &mdash; high-resolution
  cartographic mosaics, public domain.
